# 佣金结算页面整改及送审说明

## 实际业务和页面行为

档口负责人为平台授权的线下合作人员，系统按订单记录合作佣金。管理员可按订单通过微信支付分账办理佣金结算，也可在实际线下付款后登记凭证；登记线下付款本身不会触发转账。

负责人页面及工作台入口统一使用“我的佣金与结算”。自助提现关闭时，页面展示管理员统一办理的状态，不展示新申请操作，保留佣金明细、结算记录和原申请查询。自助提现开启后，按原有方式申请全部当前合格未付佣金，不允许任意填写金额或更换收款账号。

负责人页、管理员佣金付款区域以及管理员选单弹窗共用 `commissionRules` 组件，清晰展示：

- 适用对象和微信分账、线下付款两种结算方式。
- 实时符合分账条件的金额、金额计算依据和提交时复核要求。
- 自助关闭时不可自行申请；开启时平台不额外设置每日申请次数上限，已有处理中申请不得重复发起。管理员同样受处理中申请约束，单次选单范围为1至100笔。
- 无额外申请时段限制；自助关闭时由管理员办理，当前不设固定办理时段，具体安排由双方确认。分账通道未开启时明确显示不能新发起微信分账。
- 微信分账申请记录、渠道处理、实际到账为不同状态。实际到账以微信接收方结果和本人账单为准；线下付款和到账按实际记录核实，不承诺未经确认的固定到账时长。
- 进度查询、保留原申请编号、避免重复付款以及负责人页面客服咨询入口。

## 权限和异步状态处理

负责人页面初始只展示验证提示。本地负责人身份、服务端本人资料及本人收入均验证成功后才展示业务主体；页面参数不参与授予角色、确定收入归属或开启提现。

离开页面时清空已显示的资料、收入、列表和申请状态，返回后重新验证。切换账号或操作身份后，旧请求结果与旧错误均不得恢复旧数据。原申请指针仍按账号保存在本地，避免网络不确定或离开页面后丢失幂等编号。提现确认弹窗结束后再次核对操作身份；迟到的提交结果不能写入已离开的页面。

管理员详情页在服务端资料加载前不展示管理主体；身份失效或被服务端拒绝时隐藏资料、金额与付款弹窗。加载期间及返回页面时检查管理员账号和操作身份是否变化。

服务端现有鉴权、本人归属、自助开关和申请幂等规则继续作为实际权限及资金控制边界。前端隐藏和验证提示不能替代服务端校验。

## 提审前体验核对

1. 普通用户直接打开负责人收入页，以及携带 `role`、`userId`、`selfWithdrawalEnabled` 等参数打开，均应只出现访问提示。
2. 普通用户直接打开管理员负责人详情路径，不应出现管理和付款主体。
3. 已授权负责人在自助关闭状态下能查看规则、金额、明细和记录，不能提交新申请；已有申请仍能查询。
4. 已授权负责人在自助开启且分账通道可用时可按既有规则申请，确认前可阅读完整规则。
5. 负责人切换身份、账号或离开后返回，旧账户数据不得残留。
6. 管理员能查看相同规则、切换负责人自助开关并按已有方式办理分账及登记实际线下付款。
7. 用真实体验版检查规则长文滚动、金额、按钮、客服入口和旧申请查询，保存截图。自动测试及模板编译不能替代真机验收。
