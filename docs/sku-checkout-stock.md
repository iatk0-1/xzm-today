# SKU 刷新与结算库存提示

- 首页、搜索页、商品详情、心愿商品详情半屏及全屏、直播商品共用 SKU 逻辑。每次打开弹窗都重新请求商品详情，更新规格、可售库存、正常空闲现货、价格及角标；刷新期间暂不提交购买或加购，失败后需重新打开加载。
- 关闭、重新打开或切换商品后，旧请求返回的结果不再更新本次弹窗。已选数量保留在本地缓存，并按最新规格和有限库存上限收敛；售罄、已下架及失效规格沿用原禁购规则。
- SKU 弹窗点击立即购买不再主动校验或弹现货确认。带入结算页的现货数量取自打开弹窗时更新的 SKU 数据。
- 购物车进入结算时仍首次按最新正常空闲现货优先匹配，同一 SKU 多行和套装子项共享库存预算。选择或切换地址只更新运费，不静默刷新 SKU 或现货。
- 点击立即支付创建订单时，服务端仍按结算页的预期现货数量校验，并在同一事务内锁货。现货数量不足时，弹出单按钮提示“现货数量不足，请重新下单哦~”，按响应更新结算页现货数量，停止本次提交；不自动重试，也不拉起支付。
- 可售库存不足时，弹出单按钮提示“库存数量不足，请重新下单哦~”，停止本次提交，不静默减少购买件数。用户再次主动提交时重新校验。
- 原有的部分现货加备货、创建订单时原子锁货、支付取消提示和超时释放规则保持不变。后端异常文案与前端一致；精确的需求、可用量及库存快照留在服务端日志，返回的现货数量明细仅供页面更新使用。
